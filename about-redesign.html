How the plan is built

Two engines, one calendar

A run periodization engine ramps volume and intensity toward race day. An RP-style strength engine builds and maintains strength around it. Everything below is this plan's actual output, not a description of it.

What strength does as the race approaches

Accumulate · now

Normal RP mesocycle. Volume climbs MEV toward MRV, load progresses off your own logged sets.

Maintain

From Build 2. Load held, volume cut to maintenance. Keeps the strength, drops the soreness.

Through the taper it drops to movement only: pattern maintained, no new stimulus, running takes the whole recovery budget.

The one guardrail

A hard lower-body session shouldn't sit the day before a key quality run. When there's a free day the calendar shuffles it. When there isn't, it flags the conflict in place rather than letting it slide quietly. Informational, not a blocker.

Why the two clocks don't line up4-week run recovery vs 5-week strength deload ▸

The running plan's recovery weeks and the strength mesocycle's deloads run on different periods, so they never coincide every cycle. The mesocycle start offset is chosen to land deloads as close as possible to running down-weeks rather than forcing an exact match, which would distort one system to flatter the other.
